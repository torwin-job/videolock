# contrib/

Optional extras. **Not required** to use videolock.

| Path | Purpose |
|------|---------|
| `hyde/mpvpaper-wallpaper.sh` | Desktop video wallpaper via mpvpaper |
| `hyde/user-fix.sh` | Re-point hypridle + migrate legacy `~/Videos/wallpapers` assets |

Core lockscreen lives in `/bin` and `/scripts` only.
